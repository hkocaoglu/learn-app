# Taste

## Communication
- Communicates entirely in Turkish; expects assistant responses (and any UI/UI copy produced) to be in Turkish. Confidence: 0.9

## Product design
- Prefers flexible, non-locking data workflows: content must be enterable manually AND importable/exportable as JSON, with imported content remaining fully editable afterward. Confidence: 0.7
- Prefers AI/third-party integrations to be designed as optional, interface-abstracted layers (a prepared interface/contract) with a rule-based fallback so the app keeps working without an API key or connection. Confidence: 0.7
- Wants quantitative, time-aware performance tracking, not just correctness: tests should support per-test time limits (with countdown and auto-submit on expiry) and per-question time should be captured and surfaced in student reports as statistics (totals, per-question/per-topic averages). Confidence: 0.6
